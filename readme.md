# Wagon Speed Variants

Five speed and cost variants for passenger and freight wagons in **Transport Fever 3**.

Created by **Jean_Luc_Picard**.

## Download

Get the published mod from [mod.io](https://mod.io/g/transportfever3/m/wagon-speed-variants)
or the in-game Mod Hub.

This repository uses a new mod and vehicle ID. It is not a drop-in replacement
for revision 8 in existing saves. Keep the published mod.io version for those
saves, and do not enable both versions together.

## What It Does

Each independently purchasable vanilla wagon has five variants, grouped in the depot:

- **Economy:** original top speed minus 20 km/h.
- **Standard:** original top speed.
- **Rapid:** original top speed plus 20 km/h.
- **Express:** original top speed plus 40 km/h.
- **Limited Express:** original top speed plus 60 km/h.

Slower variants cost less to buy and maintain; faster variants cost more.
Appearance and capacity stay the same. Speeds use the player's selected display unit.

Urban Games' **Early Wagons** is supported automatically when active, but is not required.

## Installation

1. Subscribe to Wagon Speed Variants in the Mod Hub.
2. Enable it in your save's mod selection.

Replace or sell additional variants before removing the mod from a save.
